Passive BLE beacon scanner and GAP payload analyzer built on Zephyr RTOS.

### [Smart_chicken_coop](https://github.com/a6-a9-ai/Smart_chicken_coop)
Low-power multi-sensor acquisition and telemetry hub for automated livestock environments.  
**Arch:** Event-driven Zephyr RTOS system utilizing dedicated cooperative workqueues for low-power sensor scheduling (PIR, CO2) and BLE advertising. Custom 3-PCB stack, 3D-printed enclosure, and multi-MCU UART topology interfacing an nRF54L SoC with an ESP32.  
`C` `Zephyr RTOS` `nRF54` `ESP32` `BLE` `UART` `PCB Design`
